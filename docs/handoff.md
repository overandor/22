# Client Handoff Checklist

## Acceptance checklist
- [ ] Installation completed on target hardware.
- [ ] Ollama model pulled and reachable.
- [ ] Piper voice installed and tested.
- [ ] Microphone and playback verified.
- [ ] Notes/ideas/queue flows verified.
- [ ] Transcript archiving validated.
- [ ] UI startup and workflow demo completed.

## Deliverables
- Source code repository and dependency lock/version manifest.
- Operator quickstart and admin runbook.
- Support contact details and SLA terms.
- Change log and known limitations list.

## Recommended support model
- Hypercare: first 1-2 weeks.
- Monthly maintenance: dependency updates and runtime validation.
- Quarterly roadmap review: new tools/workflows.
